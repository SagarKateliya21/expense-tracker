⏺ This project is Spendly – a personal expense tracker web application built
  with Flask. It's designed as a step-by-step learning project for students to
  implement core features like user authentication, expense management, data
  visualization, and database integration.

  What it does:
  - Lets users register, log in, and track their expenses
  - Provides expense categorization, spending pattern analysis, and date-range
  filtering
  - Includes a clean, responsive UI with charts and interactive elements
  - Uses SQLite for data storage (to be implemented)

  Technology stack:
  - Backend: Python Flask (with Werkzeug)
  - Frontend: HTML/CSS/Jinja2 templates, custom CSS/JS
  - Database: SQLite (planned)
  - Testing: Pytest with pytest-flask

  Current state:
  The app has basic routes and templates in place, but core functionality
  (database, form handling, actual expense logic) is left as "placeholder
  routes" for students to implement in subsequent steps. The project structure
  shows clear separation between presentation (templates), static assets, and
  application logic.

  In essence, it's a practical tutorial for building a full-stack web
  application with Python Flask, focusing on real-world personal finance
  management.
